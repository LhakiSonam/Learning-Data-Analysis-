Lesson 5 — Complete a Data Analysis Project

1. Introduction
In this lesson, I will apply the Python skills I have learned to complete a real-world data analysis project.
For this project, I will use a Student Performance Dataset from Kaggle to explore students' academic performance and identify patterns in their results.

2. Project Objectives
The main objectives of this project are:

Understand and explore the dataset.
1.Clean the data by handling missing values and duplicates.
2.Calculate the average student performance.
3.Identify the highest and lowest scores.
4.Explore patterns in students' performance.
5.Create graphs to visualize the results.
6.Draw conclusions based on the data.

3. Dataset Information
-Dataset: Student Performance Dataset
-Source: Kaggle
-Tools Used:
-Python

-Pandas
-Matplotlib
The dataset contains information about students and their academic performance.
